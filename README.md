# 📦 Shipment Management System  
A lightweight, fast, and fully functional **Shipment Management Web Application** built using **HTML, CSS, JavaScript**, and **JSONPowerDB** as the backend.  
This system allows users to **add**, **retrieve**, **update**, and **reset** shipment records with a clean and simple UI.
---
## 🚀 Features

### ✔ Add Shipment  
Insert shipment details such as Shipment No., Description, Source, Destination, Shipping Date, Expected Delivery Date.
### ✔ Search Shipment by Shipment No.  
Fetch an existing shipment record instantly using JSONPowerDB.
### ✔ Update Existing Records  
Modify and overwrite old shipment information stored in the database.
### ✔ Reset Form  
Clear all input fields and return the form to its initial state.
### ✔ Real-Time CRUD  
All operations are performed instantly via JSONPowerDB APIs.

---
🗄️ JSONPowerDB Setup
Login to JSONPowerDB Dashboard
Create Database: DELIVERY-DB
Create Table: SHIPMENT-TABLE
Obtain your Connection Token
Add your token inside JS code (not uploaded to GitHub)
---
🔌 API Commands Used
➤ Insert Record — PUT
Endpoint: /api/iml
➤ Fetch Record — GET
Endpoint: /api/irl
➤ Update Record — UPDATE
Endpoint: /api/iml
